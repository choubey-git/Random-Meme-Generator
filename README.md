# 😂 Random Meme Generator

A fun and interactive Random Meme Generator built using **HTML**, **CSS**, and **JavaScript**.  
This web application fetches random memes from an online API and allows users to generate, download, and share memes instantly.

---

## 🚀 Features

- 🎲 Generate random memes
- 📥 Download memes
- 📤 Share memes on Twitter/X
- 🌐 Fetch memes using API
- 📱 Responsive and clean UI
- ⚡ Built with Vanilla JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- Imgflip Meme API
